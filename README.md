# Zoom Agricultura

App de monitoreo de plagas de suelo (bichos bolita y babosas) para
productores agropecuarios.

- `app/` — la app nativa (Expo/React Native), en construcción. Ver `app/README.md`.
- `supabase/` — esquema SQL del backend (Postgres + RLS).
- `reference/` — prototipo funcional previo y su documento de contexto. Leer
  `reference/CONTEXTO.md` antes de tocar nada.
