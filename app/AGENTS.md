# Expo SDK 54

El proyecto está fijado a **SDK 54** a propósito (no la última versión de npm) —
es la versión más nueva que tiene un cliente **Expo Go** publicado en las
tiendas de apps. Antes de subir a un SDK más nuevo, confirmar que Expo Go ya
lo soporte (o migrar a un development build propio), si no nadie va a poder
abrir el proyecto escaneando el QR.

Leer los docs versionados de esta versión antes de escribir código:
https://docs.expo.dev/versions/v54.0.0/
